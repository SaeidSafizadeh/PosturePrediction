# Posture Prediction in Static Pushing/Pulling Using ANN

This project is an early-stage research effort to **predict full-body posture** during static pushing and pulling tasks using **force measurement** and an **artificial neural network (ANN)**.

---

## 📜 Project Summary
We are developing a pipeline that:
1. **Designs & fabricates** a custom **force measurement rig** with strain gauges and a data acquisition system.
2. **Logs force data** during controlled test cases.
3. **Processes biomechanical data** in OpenSim to extract joint angles and posture descriptors.
4. **Trains an ANN** to map measured forces → predicted posture.

The ultimate goal is to enable **ergonomic assessment** and **injury prevention** without the need for full motion capture.
